# 入夜 · 中年男性睡眠指南

中文健康科普网页：从 8 类、42 项因素理解中年男性入睡困难，区分入睡困难、夜间频繁醒来和背景风险。每项包含作用、识别线索、下一步、注意边界及来源。

**在线阅读：<https://hum0r23.github.io/mens-sleep-guide/>**

## 内容

- 压力与心理状态
- 作息、生物钟与睡眠动力
- 饮品、烟酒与刺激物
- 药物、用药时点与停药反应
- 生活习惯与睡眠环境
- 需要识别的睡眠障碍
- 身体不适与躯体疾病
- 中年男性值得关注的背景因素
- 睡眠记录、CBT-I、就医分级与 28 个公开参考来源

资料查阅日期：2026-09-26。根据 NIH、NHS、AASM、Endocrine Society、FDA 和 Mayo Clinic 等公开资料作中文科普整理。不是逐字翻译，也未经过专业临床审查。此网页不能替代问诊、诊断或个体治疗建议。查阅日期不等同于原始指南更新日期。

## 使用与维护

页面是无外部依赖的静态 HTML/CSS。主要阅读、导航和详情展开不依赖 JavaScript；一小段脚本仅在打印时展开全部正文，并在打印后恢复。没有账户、表单、分析追踪、外部字体或第三方脚本，不收集健康数据。

可直接打开 `index.html`，或在目录下运行：

```sh
python3 -m http.server 8768 --bind 127.0.0.1
```

编辑 `src/guide_data.py` 中的因素正文、`src/template.html` 中的版式，以及 `build.py` 中的参考资料和补充说明后，运行：

```sh
python3 build.py
```

生成器会检查所有内部导航锚点、因素数量及重复 ID。`index.html` 是提交并发布到 GitHub Pages 的最终页面；`.nojekyll` 禁用 Jekyll 处理。
